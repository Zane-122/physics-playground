- collisions
- explosions
- throwing
- particles
- shapes
- gui
- Magnetic Forces
- more...

Each user will be able to play with all the different forces and abilities with the provided objects. 

Our project will need:
1. Shape Drawings
2. Custtomizable Gravity (by planet)
3. Basic Collisions
4. User Input (interacting with objects)
5. Explosion Physics 
6. Magnetic Physics
7. Particle Effects
8. Color / Shading
9. Toys (allow each effect to be used differntly) 
10. Restart Mechanism
